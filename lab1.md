# lab-1-Threat-vs-Vulnerabilities-
lab1 
## Threat
Anything that can potentially cause harm to an asset by exploiting a weakness. It is the source of danger, e.g. a hacker, malware, insider, or natural disaster.

## Vulnerability
A weakness or flaw in a system, process, or person that can be exploited. e.g. unpatched software, weak passwords, misconfigured firewall, untrained staff.

## Differences

| | Threat | Vulnerability |
|---|---|---|
| Nature | External or internal danger | Internal weakness |
| Control | Usually can't control it | Can fix or reduce it |
| Example | Ransomware attacker | Outdated OS |
| Role | Exploits | Gets exploited |

## Relationship
Risk = Threat × Vulnerability (× Impact)

A threat with no vulnerability to exploit is harmless. A vulnerability with no threat is not an immediate danger.

**Example:** A burglar (threat) + an unlocked door (vulnerability) = risk of break-in.
